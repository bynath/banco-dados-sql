# Projeto Banco de Dados - Biblioteca
Projeto acadêmico desenvolvido durante a disciplina de Banco de Dados, com o objetivo de aplicar na prática conceitos de criação, organização e manipulação de bancos de dados relacionais.

## Sobre o projeto
O projeto consiste na criação de um banco de dados para uma biblioteca, permitindo organizar informações sobre livros, autores, categorias, usuários e locações.
Durante o desenvolvimento foram utilizados conceitos de modelagem e SQL para criar as tabelas, estabelecer relacionamentos e realizar consultas sobre os dados.

## Objetivo
O objetivo principal deste projeto é colocar em prática os conhecimentos adquiridos na disciplina de Banco de Dados I e desenvolver uma base para estudos futuros relacionados a SQL, desenvolvimento de sistemas e análise de dados.

## Tecnologias utilizadas
- MySQL
- SQL

## Estrutura do banco
O banco de dados `Biblioteca` possui tabelas relacionadas ao gerenciamento de:
- Usuários
- Livros
- Autores
- Categorias
- Locações

## Principais conceitos utilizados
- Criação de banco de dados
- Criação de tabelas
- Chaves primárias (PRIMARY KEY)
- Chaves estrangeiras (FOREIGN KEY)
- Relacionamentos entre tabelas
- Inserção de dados
- Consultas SQL
- `SELECT`
- `JOIN`
- `WHERE`

## Consultas
O projeto também contém consultas SQL desenvolvidas para recuperar informações do banco, como:
- Usuários e seus livros locados
- Livros e seus respectivos autores
- Datas de locação
- Informações relacionadas às devoluções
